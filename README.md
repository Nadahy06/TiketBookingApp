# TiketBookingApp

Aplikasi pemesanan tiket sederhana yang dibangun menggunakan Jetpack Compose, dibuat sebagai tugas praktikum mata kuliah Pengembangan Aplikasi Mobile.

## Fitur
- Pemilihan kategori tiket (VIP / Reguler) dengan harga yang menyesuaikan otomatis
- Pengaturan jumlah tiket melalui tombol tambah/kurang (minimum 1, maksimum 10 tiket)
- Perhitungan total pembayaran otomatis berdasarkan kategori dan jumlah tiket
- Promo diskon Rp5.000 otomatis aktif untuk pembelian 3 tiket atau lebih
- Dialog konfirmasi ringkasan pesanan
- Tombol reset untuk mengembalikan pemesanan ke kondisi awal

## Teknologi
- Kotlin
- Jetpack Compose (Material 3)
